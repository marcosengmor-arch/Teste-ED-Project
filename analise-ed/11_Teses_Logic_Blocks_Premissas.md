# 11 — Teses de Marketing das 3 Ofertas: Logic Blocks e Premissas

**Projeto:** SodaFil / Bull Soda Trick · **Fonte:** transcrições PT das três VSLs (blocos 11–17 da Soda Horse, 11–16 da Alpha Erec e da Horse Jelly) · **Data:** 13/10/2026

**O que é este documento.** A tese de marketing de cada VSL (Mecanismo Único do Problema + Mecanismo Único da Solução) quebrada em *logic blocks* (seções com uma função na cabeça do prospect) e, dentro de cada bloco, em **premissas**. Premissa = **afirmativa + prova**. Cada uma recebe uma etiqueta com o tipo de prova que sustenta a afirmativa. Quando a afirmativa vem sem prova, a etiqueta diz isso ("Afirmação nua"), porque é exatamente aí que a nossa versão pode ganhar ou perder.

**Etiquetas usadas**

| Etiqueta | O que sustenta a afirmativa |
|---|---|
| Lógica Biológica | Como o corpo funciona (tecido, proteína, receptor, ácido do estômago). |
| Lógica Física | Material e mecânica (cimento seca, mangueira racha, esponja não absorve). |
| Lógica do Cotidiano | O prospect já sabe por viver (bolo cresce, bicarbonato dá arroto, pneu velho). |
| Lógica Econômica | Incentivo de quem tem dinheiro em jogo (criador, Bayer, farmacêutica). |
| Prova Científica / Especificidade | Estudo, revista, instituição, número com casa decimal. |
| Prova Documental / Visual | Exame, ressonância, régua, monitor, imagem "olha isso". |
| Prova de Autoridade | Governo, país, secretário, veterinário com 18 anos de haras. |
| Prova por Experiência Própria | O prospect confirma no próprio corpo ou na própria memória (chuveiro, matinal, Viagra enfraquecendo). |
| Prova por Caso | Um homem nomeado ou numerado (Kevin, Stallone, Mel, voluntário de 62). |
| Metáfora | Imagem que substitui a prova (balde na pedra, fio cortado, acelerador com freio de mão). |
| Callback | Reaproveita uma prova já aceita antes na VSL (RFK, câmera do Kevin, a cena da falha). |
| Fechamento Lógico | Conclusão que só existe se as premissas anteriores foram aceitas ("então não é idade"). |
| Afirmação nua | Sem prova. Vive de autoridade do narrador ou de velocidade. |
